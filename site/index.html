Everything the original did, with the controls it was missing

The tweak set is transcribed from GameTCP3 — same names, paths, types and target values. Around it sits a real safety net and a selection model that works value by value.

Per-value control

Expand any area to see every registry value it writes. Tick exactly what you want — a single value, a whole section, or a mix across areas.

Section-level speed

Click a section checkbox to select its whole list, or use Select All and Select None. A section shows ticked only when all of its values are.

Backups that restore

Every apply writes a timestamped backup first, including values that did not exist. Restore puts the old data back exactly — and backs up again before it does.

Look before you leap

Preview shows what apply would change without writing anything. Scan reports the current value next to its target, so you can see what already matches.

Stack reset included

The original 23 netsh commands — TCP/IPv4 and IPv6 reset, Winsock catalog, ARP cache and global TCP parameters — plus the four Teredo states.

One native executable

C++17 and Win32 only, statically linked. The GUI and CLI share one engine, and a built-in self test checks the tables, backup round trip and more.

Get started in a minute

Both front ends use the same engine, so you can move between them freely.

In the GUI

  1. Run GamerTCP and, if you plan to apply anything, click Restart as administrator.
  2. Expand an area and tick the values you want — or click the section to take all of them.
  3. Preview to see the exact changes, then Apply Selected.
  4. Reboot; some values only take effect at startup.

Every apply backs up the current values first, so Restore… can put things back.

From the command line

Command prompt
# see where you stand
GamerTCP status
GamerTCP preview -s tcpip,games

# apply two areas without prompting, then reboot
GamerTCP apply -s tcpip,games -y

# save the current values, and put them back later
GamerTCP backup D:\backups\before-gamertcp.txt
GamerTCP restore D:\backups\before-gamertcp.txt

# inspect and run the built-in checks
GamerTCP teredo show
GamerTCP selftest

Built to be undone

Registry tuning is not universally beneficial, so the tool makes it easy to measure, compare and revert.

Backup first

A timestamped backup is written before every apply, recording values that did not exist as well.

Dry run

preview and the GUI's Preview show each change without touching the registry.

Exact restore

Restore replays a backup, deletes values that were missing, and takes a fresh backup of its own first.

Per-value failures

Deprecated or removed parameters fail individually and are reported; the run keeps going.

Questions

The honest answers, including the ones that are not a sales pitch.

Do I need administrator rights?

Only to change something. Reading values, scanning, previewing and writing backups work as a normal user. Applying, restoring, resetting the stack and changing Teredo require an elevated prompt — the GUI shows a read-only banner with a restart button until then.

Will this lower my ping?

Not necessarily. Registry and TCP/IP tuning is not universally beneficial, and the upstream project labels itself experimental. Some values help on some networks and do nothing — or hurt — on others. Measure before and after, and keep the backup.

What exactly gets changed?

106 values across 15 sections, from TCP/IP parameters such as DefaultTTL, TcpAckFrequency and TcpNoDelay, through per-interface settings applied recursively, to DNS cache, multimedia throttling, the games task profile, LanmanServer, NetBT, policies and miscellaneous entries. Applying also runs the original 23 netsh reset commands unless you skip the reset.

Can I undo everything?

Yes. Each apply writes a timestamped backup before writing, and restore (or Restore… in the GUI) puts the recorded values back, including deleting values that did not exist before. Restoring is the only exact undo for an apply, and a backup is taken before a restore as well.

Does it need .NET or a runtime?

No. The executable is statically linked C++ with no .NET, no Visual Basic runtime, no VC++ redistributable and no third-party libraries. The installer is optional and equally self-contained.

What does the installer do, and how do I remove it?

It copies the executable and the documentation into %LOCALAPPDATA%\Programs\GamerTCP4, creates a Start Menu shortcut and registers an entry under Settings > Apps, all for the current user. Remove it from Settings > Apps, or run Uninstall.exe --uninstall in the install folder.

Which Windows versions are supported?

Windows 10 and Windows 11 on x64, and ARM64 under x64 emulation. Some legacy parameters no longer exist on newer builds; those writes fail individually and are listed, without stopping the rest of the run.
